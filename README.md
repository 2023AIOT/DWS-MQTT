DWS-MQTT: A High-Performance Distributed MQTT Communication Method for Industrial Internet of Things



This repository provides the implementation of DWS-MQTT and compared baseline methods used in the experimental evaluation.



The repository includes:

\- DWS-MQTT

\- DMQTT

\- TD-MQTT

\- TopoMQTT

\- ARPS-based routing optimization



\## Environment

The experiments were conducted under the following environment:

\- Python: 3.9

\- MQTT Broker: Mosquitto 2.0.20

\- MQTT Client Library: Eclipse Paho MQTT 2.1.0

Hardware:

\- CPU: Intel(R) Core(TM) i5-9300H
